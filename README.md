# LaboratorioAnalisis — Sistema de reservas de biblioteca

Laboratorio individual de *Análisis y diseño de sistemas de información*:
identificación e implementación de patrones de diseño (Builder, Strategy, Facade,
Observer y State) en un prototipo de consola en Java 17+.

**Autor:** Samuel Velásquez Rojas

## Organización por ramas

Cada estación del laboratorio está en su propia rama y parte de la anterior:

| Rama | Estación |
|---|---|
| `estacion-1` | Comprender el problema y modelar el flujo |
| `estacion-2` | Crear el dominio y ejecutar la primera versión |
| `estacion-3` | Construir reservas con Builder |
| `estacion-4` | Seleccionar salas con Strategy |
| `estacion-5` | Separar el acceso a datos y coordinar con Facade |
| `estacion-6` | Notificar eventos con Observer |
| `estacion-7` | Controlar el ciclo de vida con State |
| `estacion-8` | Integrar y ejecutar la aplicación completa |

## Ejecución

Abrir la carpeta `BibliotecaReservas` en el IDE, marcar `src` como carpeta de
fuentes y ejecutar `biblioteca.Main`.
